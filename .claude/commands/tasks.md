Показать, что сейчас в работе по проекту bunch-package.

## Шаги

1. `list_tasks(projectId: "bunch-package", limit: 50)` — все, кроме `done` и
   `cancelled`, сгруппировать по статусу: `in_progress`, `review`, `todo`,
   `backlog`.

2. Вывести таблицей: короткий id, тег модели, приоритет, заголовок. Тег брать из
   тегов задачи (`opus` / `sonnet` / `haiku` / `fable`).

3. **Задача без тега модели — дефект заведения.** Называть отдельной строкой
   под таблицей: «без тега: TSK-NN, TSK-MM — поставить по критериям
   `.claude/rules/mionika.md`». Не проставлять молча.

4. Если спросили про конкретную глубину — фильтровать:
   `list_atoms(projectId: "bunch-package", type: "task", tags: "opus")`.

5. Одной строкой в конце — что стоит взять следующим и почему: приоритет,
   зависимости, задачи, на которые уже есть измерения в mIOnika.
