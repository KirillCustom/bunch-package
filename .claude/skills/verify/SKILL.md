# Доказательство правки

Зелёная сюита здесь доказательством не считается. Причина измерена: при 36 зелёных тестах корпус дал 17 поражений против patch-package и 0 побед — тесты и разборщик писал один человек в одном представлении о формате.

Доказательства два: **корпус** (правка не изменила поведение на реальных патчах) и **мутация** (тест действительно закрепляет правку).

## Мутация — всегда

Каждая правка заканчивается этим. Снимаешь правку — тест обязан покраснеть; не покраснел, значит он проверяет не то.

```bash
SB=<каталог песочницы сессии>
cp src/файл.ts $SB/файл.bak          # копия ДО мутации
# ... внести мутацию (python3 с точечной заменой строки) ...
bun test -t "имя теста"              # ожидание: 0 pass, 1 fail
cp $SB/файл.bak src/файл.ts          # восстановление ИЗ КОПИИ
grep -n "<мутированная строка>" src/файл.ts   # убедиться, что вернулось
```

**Никогда не восстанавливать через `git checkout <файл>`.** Работа в ветке обычно ещё не закоммичена, и `checkout` снесёт её целиком. Это уже случалось дважды.

Мутация, пережившая сюиту, — это дыра в тестах, а не повод пожать плечами. Исключение одно и описано в коде: проверка «патч не может быть записан за пределы `patches/`» в `writePatch` — до неё не добраться, `validateManifestField` отвергает такие поля раньше. Это второй замок на той же двери, оставлен намеренно.

## Корпус — когда правка задела разбор, применение или откат

Стенд: `/Users/kirillcustom/.claude/jobs/0d36b312/tmp/corpus`

Внутри: `files/` — 300 патчей из публичных репозиториев, `indexed.tsv` — их список, `pp/` — эталонный patch-package 8.0.1, `../oldcode/index.ts` — код проекта до правок, с которым сверяется каждый прогон. Три скрипта:

| скрипт | что проверяет | норма | когда обязателен |
|---|---|---|---|
| `run.ts` | дерево после нашего `apply` против patch-package | **291/291** | разбор, применение, построение путей |
| `idempotent.ts` | второй `apply` ничего не меняет | **289 idempotent, 0 NOT-idempotent** | там же |
| `roundtrip.ts` | `apply` + `rebase 0` возвращает эталон побайтово | **289 restored, 1 not-restored** | откат, инверсия патча |

Единственный неустранимый `not-restored` — `react-native-launch-navigator+1.0.8`: хунк `@@ -1 +1 @@` в файле из одной строки, исходный перевод строки не сохранился ни в файле, ни в патче. Ещё один патч, `@radix-ui+react-dialog+1.1.6`, стабильно даёт `apply-failed` в roundtrip. От одного до трёх `no-install` за прогон — это реестр, а не мы.

### Как запускать

Каждый скрипт шардируется. Три шарда параллельно, весь прогон ~25 минут; `run.ts` и `roundtrip.ts` можно гонять одновременно — у них разные рабочие каталоги.

```bash
cd /Users/kirillcustom/.claude/jobs/0d36b312/tmp/corpus
for i in 0 1 2; do (bun run.ts $i 3 > shard-$i.log 2>&1 &); done
```

Ждать — фоновой командой, а не опросом:

```bash
C=/Users/kirillcustom/.claude/jobs/0d36b312/tmp/corpus
until [ "$(grep -l 'готов' $C/shard-0.log $C/shard-1.log $C/shard-2.log 2>/dev/null | wc -l | tr -d ' ')" = "3" ]; do sleep 10; done
```

### Как читать итог

`run.ts` печатает сводку в каждый лог:

```bash
for i in 0 1 2; do sed -n '/^сравнено/,$p' shard-$i.log | head -5; done
```

`idempotent.ts` и `roundtrip.ts` пишут JSON — итог собирать из него:

```bash
bun -e '
const fs=require("fs");
const all=[0,1,2].flatMap(i=>JSON.parse(fs.readFileSync(`roundtrip-${i}.json`,"utf-8")));
const by={}; for(const o of all) by[o.status]=(by[o.status]??0)+1;
console.log(all.length, by);
for(const o of all.filter(o=>o.status!=="restored"&&o.status!=="no-install")) console.log(o.status, o.file);
'
```

### Столбец «совпало со старым нашим»

`oldcode` — снимок кода до всех правок, а не движущаяся цель. Расхождение с ним означает «поведение изменилось» — иногда это и есть цель правки. Тогда его надо объяснить, а не молча принять. Расхождение с **patch-package** объяснять сложнее: на нём держится обещание проекта, и менять его можно только осознанно.

### Чего корпус не ловит

Вложенных зависимостей (`outer++inner`) в нём нет ни одной, секций с симлинками (`mode 120000`) — тоже. Эти случаи закрываются сюитой сквозняком.
